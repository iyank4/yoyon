# yoyon (AionUi fork)

This repository is a **fork of the original [AionUi](https://github.com/iOfficeAI/AionUi)** project. The primary development branch for this fork is **`yoyon`**. All new features, experiments, and customizations live here while the upstream `main` branch continues to receive the official roadmap and releases.

## Contributing

- To improve the original AionUi, fork its repository (https://github.com/iOfficeAI/AionUi) and submit a pull request upstream.

Please follow the upstream project's contribution guide and code conventions.

## Why a Fork?

Maintaining a separate branch gives us the flexibility to:

- **Prototype quickly** without waiting on upstream release cycles.
- **Add custom UI/UX tweaks** tailored to specific workflows.
- **Experiment with new integrations** (e.g., local model back‑ends, additional agents) while keeping the mainline stable.

We hope this fork serves as a friendly playground for developers to explore AionUi's capabilities and, when appropriate, give back improvements to the original project.
